7. **HDMI の入力（HPD と EDID の確認。P2b-3 のファームウェアの PR がマージされたあとで行う）**: PC 直結（KVM なし）、PC の解像度を 720p60 に設定。**使用するファームウェアと設定、EDID（最初は 720p60 だけ）の識別と書き込み完了の条件、HPD を Low / High にする方法は、P2b-3 の PR の本文に従う**（依頼元が定義する。ここでは定義しない）。**判定（案）**: HPD が Low の間は PC がディスプレイを認識しない、High にすると PC が認識して、解像度の候補に 720p60 が出る（E12）。**`HDET`（2 番）は、HPD の代わりにならない**（何を検出する信号かが未確認）ため、HPD の判定には使わない。
8. **`VDD_MIPI_DPHY` の測定**: P2b-2 の PR がマージされたあとで、E14 の方法で測る（CSI ケーブルは接続しない）。
