## E. HDMI キャプチャ Geekworm X630 v1.5

調査メモ（2026-10-15、Geekworm 公式 Wiki/製品ページには本環境から接続できず、検索結果の要約に基づく。**一次情報で要確認**）:
- TC358743XBG 搭載、CSI-2 は **15pin FPC / 1.0mm ピッチ**。Raspberry Pi 4B/3B+/3B/3A+/Zero 系向け（= 2 レーン）。
- v1.5 は DIP スイッチ（ハード/ソフトリセット）を廃止し、HDMI の back-powering 問題を修正したとされる。
- 解像度は販売ページ等で **1080p/25fps まで**と記載（Wiki の表では 1080p@50 とも読め、情報が食い違う）。HANDOFF 4章の「1080p30 上限」の前提と食い違う可能性。
