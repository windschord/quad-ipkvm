# 実機確認チェックリスト (HW_VERIFY)

オーナー（人間）が実機で確認し、結果を各項目の「結果」欄に記入する。
**未記入の項目に依存する実装は `TODO(hw-verify)` を残したまま進める。** 推測で埋めない。

記入ルール: 値は「測定値 + 測定条件（テスタ/オシロ、何と何の間、日付）」まで書く。

## A. KVM（AliExpress 4ch HDMI KVM、型番不明）— HANDOFF 6章 1,2,6

| # | 確認項目 | 方法 | 結果 |
|---|---|---|---|
| A1 | 型番・外観・基板写真（ボタン/LED 周辺） | 基板を開けて撮影し `docs/img/` に保存 | |
| A2 | ボタンは 4 個独立か、巡回する 1 個か | 手で押して LED の遷移を観察。基板の配線を追う | |
| A3 | ボタン端子の電圧（開放時） | テスタ: ボタン端子—GND 間（3.3V / 5V / その他） | |
| A4 | 押下で GND に落ちるか。押下時の電流 | ボタンを押しながら端子—GND 間を測定。可能なら押下時の電流 | |
| A5 | 4 ボタンの共通線（マトリクス配線でないか） | 導通チェックでボタン端子の共通性を確認 | |
| A6 | LED の駆動電圧と極性（アクティブ High/Low）、点灯時の電圧、1 点灯 1 チャンネルか | テスタ: LED 端子—GND 間を各チャンネル選択時に測定 | |
| A7 | LED の点灯方式（常時点灯/PWM/点滅、全消灯の状態があるか） | 目視 + オシロ（可能なら） | |
| A8 | 自動スキャン機能の有無（LED が勝手に巡回しないか） | 説明書/実機 | |
| A9 | 絶対座標ポインタが KVM を通るか | P4 完了後に PC 直結と KVM 経由で比較 | |
| A10 | 手動切替から HDMI 再同期までの時間 | 目視/ログ（P5 で計測） | |
