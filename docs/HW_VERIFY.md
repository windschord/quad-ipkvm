## E. HDMI キャプチャ Geekworm X630 v1.5

調査メモ（2026-10-15、Geekworm 公式 Wiki/製品ページには本環境から接続できず、検索結果の要約に基づく。**一次情報で要確認**）:
- TC358743XBG 搭載、CSI-2 は **15pin FPC / 1.0mm ピッチ**。Raspberry Pi 4B/3B+/3B/3A+/Zero 系向け（= 2 レーン）。
- v1.5 は DIP スイッチ（ハード/ソフトリセット）を廃止し、HDMI の back-powering 問題を修正したとされる。
- 解像度は販売ページ等で **1080p/25fps まで**と記載（Wiki の表では 1080p@50 とも読め、情報が食い違う）。HANDOFF 4章の「1080p30 上限」の前提と食い違う可能性。
- **EDID はデフォルトでチップに書き込まれていない**とされる。ファームが I2C で EDID を書く必要がある（HANDOFF 4章の「自作 EDID」方針は必須になる）。
- X630 の Wiki の GPIO 表（HDET/INT/RST/I2S）は音声拡張ボード X630-A2 のもの。**素の X630 では RESET/INT が 15pin コネクタに出ていない可能性**がある。

## F. ネットワーク（Ethernet）— P3-0

回路図（`docs/ESP32-P4-ETH-schematic.pdf` の ETHERNET / IP101GRI 部。**画像を目視で読み取った値**で、実機での確認が必要）:

| 信号 | GPIO | 備考 |
|---|---|---|
| TXD0 / TXD1 | 34 / 35 | |
| TX_EN | 49 | |
| RXD0 / RXD1 | 29 / 30 | |
| CRS_DV (RXDV) | 28 | |
| REF_CLK（RXCLK、PHY が出す 50MHz） | 50 | MAC 側は外部クロック入力 |
| MDC / MDIO | 31 / 52 | |
| PHY RESET | 51 | |

PHY は IP101GRI。B 章の GPIO 候補（ATX・パネル用）とは重複しません。

**独立した裏付け**: ESP-IDF v6.0.1 の `components/esp_eth/include/esp_eth_mac_esp.h` にある ESP32-P4 向けデフォルト設定 `ETH_ESP32_EMAC_DEFAULT_CONFIG()` が、上の RMII 結線（MDC=31, MDIO=52, REF_CLK=50 の外部入力, TX_EN=49, TXD0=34, TXD1=35, CRS_DV=28, RXD0=29, RXD1=30）と**完全に一致**します（回路図の目視読み取りと一致。ただし F1 の実機確認は引き続き必要）。

**PHY ドライバ**: ESP-IDF 6.0 では `esp_eth_phy_new_ip101()` を含む個別 PHY ドライバが IDF から**削除**され、外部リポジトリ（esp-eth-drivers、コンポーネントレジストリ）に移りました（移行ガイド `docs/en/migration-guides/release-6.x/6.0/networking.rst`）。P3-0 では IEEE 802.3 準拠の汎用ドライバ `esp_eth_phy_new_generic()` を使います（IP101GRI は基本機能なら動く想定。動かなければ F6 の手順）。RMII クロックの Kconfig も IDF 6.0 で削除済みで、設定は EMAC の構造体だけで行います。
