## E. HDMI キャプチャ Geekworm X630 v1.5

調査メモ（2026-10-15、Geekworm 公式 Wiki/製品ページには本環境から接続できず、検索結果の要約に基づく。**一次情報で要確認**）:
- TC358743XBG 搭載、CSI-2 は **15pin FPC / 1.0mm ピッチ**。Raspberry Pi 4B/3B+/3B/3A+/Zero 系向け（= 2 レーン）。
- v1.5 は DIP スイッチ（ハード/ソフトリセット）を廃止し、HDMI の back-powering 問題を修正したとされる。
- 解像度は販売ページ等で **1080p/25fps まで**と記載（Wiki の表では 1080p@50 とも読め、情報が食い違う）。HANDOFF 4章の「1080p30 上限」の前提と食い違う可能性。
- **EDID はデフォルトでチップに書き込まれていない**とされる。ファームが I2C で EDID を書く必要がある（HANDOFF 4章の「自作 EDID」方針は必須になる）。
- X630 の Wiki の GPIO 表（HDET/INT/RST/I2S）は音声拡張ボード X630-A2 のもの。**素の X630 では RESET/INT が 15pin コネクタに出ていない可能性**がある。

| # | 確認項目 | 方法 | 結果 |
|---|---|---|---|
| E1 | X630 のレーン数（2）、CSI 15pin のピン表（3V3/SDA/SCL/CAM_GPIO/CAM_CLK/D0/D1/CLK の割当）を X630 の Wiki・回路図で確認 | Wiki/回路図/実機 | |
| E2 | **22pin(0.5mm) ↔ 15pin(1.0mm) 変換ケーブルの入手**（Raspberry Pi 5 用カメラケーブル相当）。ピン対応（ESP32-P4-ETH J1 のピン 1=3V3, 2=SDA, 3=SCL, 5/6=CSI_IO1/IO0, 14/15=CLK, 17/18=D1, 20/21=D0）と X630 側の対応、ケーブルの向き（接点面） | 回路図 + 導通確認 | |
| E3 | TC358743 の I2C アドレス（Linux ドライバ既定は 0x0F）と、I2C 速度、プルアップ位置（ESP32-P4-ETH 側は 2.2kΩ→3.3V） | I2C スキャン（P2a 診断ログ） | |
| E4 | RESET/INT が CSI コネクタ経由で ESP から見えるか。見えない場合のリセット手順（ソフトリセットのみ）と INT のポーリング方針 | 回路図/実機 | |
| E5 | 実際に取れる最大モード（1080p25 / 30 / 50 / 60）。2 レーン帯域とファームの EDID 方針（HANDOFF 4章）との整合 | P2b の実機ログ | |
| E6 | X630 の電源（3.3V/5V どちらから給電されるか、消費電流）と ESP32-P4-ETH の 3V3 で足りるか | 回路図/テスタ | |
| E7 | HDMI back-power の有無（ターゲット PC から X630 へ給電される場合、ESP 側と電位が競合しないか） | 実機 | |
| E8 | KVM 経由時のホットプラグ/HPD の挙動（KVM 切替で HPD が落ちるか） | P5 | |
